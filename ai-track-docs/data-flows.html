vscode-chef Data Flows

Animated view mapped to real repository paths. Use buttons to isolate one flow.

1. Ruby lint diagnostics

extension.ts spawns cookstyle/rubocop, parses JSON offenses, and updates VS Code diagnostics.

2. Courier job schema validation

package.json maps **/*job.json to schema/job-schema.json; snippets scaffold valid structures.

3. Snippet generation + CI gate

autogeneration regenerates snippets; CI validates JSON, renders Mermaid diagram, then packages VSIX.
